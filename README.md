# Task-5-github-pages
Task 5: Host a Static Website with GitHub Pages

Objective

Deploy a simple static website using GitHub Pages.

Tools Used

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

Project Description

I created a static website using HTML and CSS. The website contains a welcome heading, project information, a link to GitHub Pages documentation, and a footer.

Steps Performed

1. Created an "index.html" file.
2. Added HTML and CSS to design the website.
3. Created a new public GitHub repository.
4. Uploaded the website files to GitHub.
5. Enabled GitHub Pages from the "main" branch using the root folder.
6. Opened the published website and verified that it works.

Result

The website was successfully deployed and is accessible online using GitHub Pages.
